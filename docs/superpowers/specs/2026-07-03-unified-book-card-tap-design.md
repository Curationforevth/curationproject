# 책 카드 탭 인터랙션 통일 + 2단계 확장 시트 — 설계

- 날짜: 2026-07-03
- 상태: Eden 승인 (섹션 1·2 대화 승인, 3·4는 리뷰 사이클로 검증)
- 배경: Eden 지시 백로그 #0 "어디서든 책 카드 탭 = 동일한 상세 바텀시트".
  IA 스펙(2026-04-03)이 원래 "내 책 카드 탭 → 상세 바텀시트"(L85), "검색 결과 탭 →
  상세 바텀시트"(L56)로 정의했으나 현재 코드가 이탈 — 본 작업은 스펙 복원 + 완성.

## 0. 핵심가치 정렬 (설계 판단 기준)

| 핵심가치 | 이 설계가 기여하는 방식 |
|---|---|
| ①서재 경험 | 서가 감상 중 풀페이지 이탈 제거(시트로 맥락 보존), 죽은 탭 소멸 |
| ②취향 발견 | 피드백 최단 경로(1탭) 무손실 보존 + 신호 수집면(삭제/관심없어요/북마크) 서재·검색까지 확대 |
| ③맞춤 추천 | "비슷한 책" 노출 표면 앱 전체 확대 + 확장 시트에서 그리드로 소비 면적 증가 |

레퍼런스: Netflix(카드 탭=프리뷰 시트, 카드 내 버튼=직행), Google Maps(시트 드래그
→ 풀페이지 모프). MOODBOARD는 폐기됨(Eden 지시) — 본 문서가 인터랙션 정본.

## 1. 인터랙션 모델 (규칙)

1. **카드 영역 탭 = 상세 시트.** 홈 전 섹션(큐레이션/트렌딩/추천/읽고싶은책/내 책)·
   서재 책등(BookSpine)·서재 읽는 중 카드·검색/등록 결과. 예외는 온보딩(다중선택 모드)뿐.
2. **카드 안의 버튼 = 액션 직행.** 내 책 카드 [피드백 남기기]·[다 읽었어요], 읽는 중
   카드 [다 읽었어요]는 버튼으로 유지 — IA 스펙 "1탭+피드백" 저니 보존.
3. **시트는 2단계.** peek(~0.65) = 현행 무게의 프리뷰+퀵액션 / 위로 드래그 → 확장(1.0)
   = 풀페이지 경험. 정보·입력을 peek에 추가하지 않는다.
4. **`/book/{userBookId}` 풀페이지 유지, 역할 재정의.** 책 정보 딥뷰=확장 시트,
   `/book` 페이지="내 기록"(평가 보기·수정) 전용. 진입은 시트의 [내 평가 보기·수정].
   별도 "자세히 보기" 링크는 두지 않는다.
5. **롱프레스 정리.** 홈 내 책·읽고싶은책 카드의 롱프레스=시트 제거(탭과 중복).
   서가 뷰 롱프레스=드래그 정렬은 **이미 구현·배포되어 있음**(bookshelf_row.dart
   `_DraggableSpine`, reorderBooks 영속화 — QA 확인으로 "미구현" 오기 정정) — 탭=시트와
   제스처 아레나 충돌 없음.
6. **무거운 입력은 풀페이지 플로우 유지.** 피드백 작성/수정은 지금처럼 `/feedback` 라우팅.

## 2. 2단계 시트 동작

### Peek (기본, initialChildSize ≈ 0.65)
- 구성 현행 유지: 표지+제목+저자+ShelfStatusBadge, 책 소개 2~3줄 클램프,
  ShelfAwareActions, 비슷한 책 가로 1행, ShelfDeleteAction/NotInterestedAction.
- 퀵액션이 접힘 없이 보이는 높이. 상단에 확장 셰브론(∧) — 접근성 대체 진입.

### 확장 (maxChildSize 1.0)
- 모서리 라운드 → 0, 상단 고정 헤더(제목+✕) 등장 (Google Maps 모프).
- 책 소개 전문 노출.
- 비슷한 책: 가로 1행 → 2열 그리드 (기존 /similar 응답 재사용, 추가 네트워크 없음).
- 행동 버튼 구성 동일 (스크롤 상 위치만 변화).

### 메커니즘
- `showModalBottomSheet(isScrollControlled)` + `DraggableScrollableSheet`
  (snap: [0.65, 1.0], expand:false). 시트 내부 스크롤 컨트롤러 = builder 제공 컨트롤러.
- `DraggableScrollableController` extent 리스닝 → 라운드/헤더/레이아웃 보간.
- 확장에서 아래로 드래그 → peek 스냅, 더 내리면 dismiss.
- **접근성**: iOS accessibleNavigation 에선 드래그 스냅이 어려움 → 셰브론 탭으로
  `controller.animateTo(1.0)`. 스낵바는 전역 규칙대로 showTimedSnackBar 만 사용.
- pop 이후 위젯 ref 금지 — 기존 ProviderContainer 캡처 패턴 유지 (#14 함정).

## 4. 검증 전략

- **유닛/위젯**: ①시트 peek→확장 스냅 + 셰브론 탭 확장 ②확장 상태 그리드 전환
  ③각 지점 탭→시트 오픈(기존 book_detail_test/shelf_aware_actions_test 패턴 재사용)
  ④내 책 카드: 버튼 탭=피드백 라우팅(1탭 저니 회귀 방지 고정) ⑤검색 기등록 책
  탭=시트 오픈 ⑥롱프레스 핸들러 부재 확인.
- **기존 테스트 갱신**: my_books CTA 관련, 검색 상태선택 시트 관련.
- **실기기(Eden)**: 드래그 스냅 감각, accessibleNavigation 셰브론, 서가 탭 체감.
- 서버 변경 없음 → prod E2E/CODE_REV 불필요. flutter test 전량 green 이 머지 게이트.

## 5. 저니 회귀 체크리스트 (리뷰 사이클용)

| 저니 | 목표 | 확인 |
|---|---|---|
| 홈→등록 | 2탭 (카드→시트→읽는 중) | 유지 |
| 홈→피드백 (내 책) | 1탭+피드백 (버튼 직행) | 버튼 유지로 보존 |
| 서재→다 읽었어요 | 1탭+피드백 | 버튼 유지로 보존 |
| +→등록 | 3탭 (+→검색→책→시트 버튼) | 시트 버튼이 상태선택 대체, 유지 |
| 기등록 책 재탭 | (신규) 시트로 상태 확인/변경 | 죽은 탭 소멸 |
| 서가 감상 | 맥락 이탈 없음 | 시트 peek 로 보존 |
| 평가 수정 | 시트→[내 평가 보기·수정]→/book | 유지 |
